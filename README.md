Project 1: Hangman Game

Description

A terminal-based Hangman game developed using Python.

The user attempts to guess a hidden English word letter by letter within 6 incorrect attempts.

Features

- Random word selection
- Letter-by-letter guessing
- ASCII Hangman graphics
- Tracks guessed letters
- Prevents duplicate guesses
- Win and Game Over screens

Technologies Used

- Python 3
- Random module

How to Run

1. Download "hangman.py".
2. Install Python 3.
3. Run the following command:

python hangman.py
